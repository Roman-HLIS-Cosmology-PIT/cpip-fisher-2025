# Fisher Forecasts for Cosmological Yields from 3×2pt Analysis of the Roman Space Telescope High Latitude Imaging Survey

This repository contains code for modified coordinate descent and Fisher information analysis used in [K. Cao et al. (2026)](https://ui.adsabs.harvard.edu/abs/2026arXiv260100438C/abstract).
The code depends on K. Cao's [CoCoA](https://github.com/CosmoLike/cocoa.git) installation on [the Ohio Supercomputer Center](https://www.osc.edu/), and the code snippets need to be customized before reuse.
